## Modification Tips

### To Make Presets Stronger:
- Increase Clarity/Texture by +5 to +10
- Increase Contrast by +5 to +10
- Increase Saturation by +5
- Increase Grain Amount by +10

### To Make Presets Subtler:
- Reduce all adjustments by 30-50%
- Decrease Grain Amount by -5 to -10
- Reduce Vignette strength

### To Adapt for Different Cameras:
- **High-resolution sensors:** Reduce Clarity/Texture
- **Phone cameras:** Reduce Grain, increase Sharpness
- **Older cameras:** Reduce Noise Reduction settings

### To Create Your Own Variations:
1. Apply base preset
2. Adjust temperature to match your lighting
3. Modify saturation to taste
4. Fine-tune shadows/highlights for your subject
5. Save as new preset with descriptive name

## Technical Notes

### XMP Format
These presets use Adobe XMP (Extensible Metadata Platform) format which is:
- Universal across Lightroom products
- Human-readable XML
- Non-destructive
- Preserves all adjustment data

### Process Version
All presets use Process Version 11.0 (latest as of 2026), ensuring:
- Modern color science
- Better highlight recovery
- Improved color grading tools
- Enhanced texture controls

### Compatibility
Settings are optimized for:
- Lightroom Classic CC 2020+
- Lightroom CC (Cloud) 2020+
- Lightroom Mobile 6.0+
- Adobe Camera Raw 13.0+

### Performance
Each preset contains:
- ~150 lines of XML
- File size: ~5KB each
- Instant application time
- No external dependencies
