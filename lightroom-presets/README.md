# Lightroom Presets - Japanese Styles & Ricoh GR IV Film Simulations

คอลเลกชั่นพรีเซ็ต Lightroom ที่จำลองสไตล์ถ่ายภาพญี่ปุ่นและโหมดฟิล์มจากกล้อง Ricoh GR IV สำหรับใช้กับ Lightroom Mobile และ Desktop

## 📦 ไฟล์ที่รวมอยู่

### Japanese Styles (สไตล์ญี่ปุ่น)

1. **Japanese Soft Film** - ฟิล์มนุ่มสไตล์ญี่ปุ่น
2. **Tokyo Street** - สไตล์ถนนโตเกียว
3. **Kyoto Moody** - บรรยากาศเกียวโต

### Ricoh GR IV Film Simulations

4. **Ricoh GR Positive Film** - จำลองโหมด Positive Film
5. **Ricoh GR Negative Film** - จำลองโหมด Negative Film  
6. **Ricoh GR Snap** - จำลองโหมด Snap

## 📱 วิธีนำเข้าใน Lightroom Mobile

### สำหรับ iOS:
1. บันทึกไฟล์ .xmp ลงใน iCloud Drive หรือ Files
2. เปิด Lightroom Mobile
3. ไปที่ Presets → ปุ่ม ⋮ → Import Presets
4. เลือกไฟล์ .xmp ที่ต้องการ
5. พรีเซ็ตจะปรากฏในกลุ่ม User Presets

### สำหรับ Android:
1. บันทึกไฟล์ .xmp ลงในโฟลเดอร์ของเครื่อง
2. เปิด Lightroom Mobile
3. ไปที่ Presets → ไอคอน ⋮ → Import Presets
4. เลือกไฟล์จากที่เก็บข้อมูล
5. พรีเซ็ตพร้อมใช้งาน

## 💻 วิธีนำเข้าใน Lightroom Desktop

1. เปิด Lightroom Classic
2. ไปที่ Develop Module
3. คลิกขวาที่ Presets Panel → Import
4. เลือกไฟล์ .xmp ทั้งหมดที่ต้องการ
5. พรีเซ็ตจะปรากฏใน User Presets

## 🎨 รายละเอียดแต่ละพรีเซ็ต

### 1. Japanese Soft Film
**ลักษณะ:** ฟิล์มนุ่ม สีพาสเทล บรรยากาศอบอุ่น
- คอนทราสต์ต่ำ (-15)
- เงาเพิ่มขึ้น (+30)
- สีส้มและเหลืองเพิ่ม (Warm tones)
- Film grain 30%
- Vignette เบาๆ
- เหมาะสำหรับ: ภาพบุคคล, ธรรมชาติ, บรรยากาศอบอุ่น

### 2. Tokyo Street
**ลักษณะ:** คมชัด สีเย็น ไฮคอนทราสต์
- คอนทราสต์สูง (+25)
- Clarity & Texture เพิ่ม
- เงาลดลง (-20)
- สีน้ำเงินและฟ้าเด่น
- Split toning น้ำเงินในเงา
- เหมาะสำหรับ: ถนน, เมือง, สถาปัตยกรรม, Night photography

### 3. Kyoto Moody
**ลักษณะ:** สีเข้ม บรรยากาศหนักแน่น โทนดิน
- Saturation ลดลง (-15)
- Highlights ลดลงมาก (-40)
- โทนสีส้ม-น้ำตาล
- Film grain นุ่ม 25%
- Vignette กลม
- เหมาะสำหรับ: วัด, ป่าไม้, บรรยากาศเงียบสงบ

### 4. Ricoh GR Positive Film
**ลักษณะ:** สีสดใส อบอุ่น คอนทราสต์พอดี
- Temperature อบอุ่น (+10)
- Vibrance & Saturation เพิ่ม
- คอนทราสต์ปานกลาง (+20)
- สีทุกช่วงเพิ่มขึ้น
- Film grain เบา 10%
- เหมาะสำหรับ: ภาพทั่วไป, Travel, Portrait

### 5. Ricoh GR Negative Film
**ลักษณะ:** สีซีด นุ่มนวล โทนเย็น
- คอนทราสต์ต่ำ (-10)
- Saturation ลดลง (-12)
- เงาเพิ่มขึ้น (+20)
- โทนสีเย็นเล็กน้อย
- Film grain นุ่ม 20%
- เหมาะสำหรับ: Portrait, Documentary, Vintage look

### 6. Ricoh GR Snap
**ลักษณะ:** สมดุล เน้นความคม เหมาะถ่ายสแนป
- Clarity & Texture เพิ่ม
- คอนทราสต์ปานกลาง (+15)
- สีธรรมชาติแต่ Punchy
- Sharpness เพิ่มขึ้น
- Film grain เบามาก 8%
- เหมาะสำหรับ: Street photography, Candid, Everyday shots

## ⚙️ การปรับแต่ง

พรีเซ็ตเหล่านี้เป็นจุดเริ่มต้น คุณสามารถปรับแต่งเพิ่มเติมได้:
- **Exposure** - ปรับตามแสงของภาพ
- **White Balance** - ปรับตามสภาพแสง
- **Highlights/Shadows** - ละเอียดจูนตามภาพ
- **Saturation** - เพิ่มหรือลดตามความชอบ

## 📸 เทคนิคการใช้งาน

1. **ถ่ายในไฟล์ RAW** เพื่อผลลัพธ์ที่ดีที่สุด
2. **ตั้งค่า White Balance ให้ถูกต้อง** ก่อนใช้พรีเซ็ต
3. **ทดลองหลายพรีเซ็ต** เพื่อหาสไตล์ที่เหมาะกับภาพ
4. **ปรับแต่งต่อ** หลังใช้พรีเซ็ตเพื่อความสมบูรณ์แบบ
